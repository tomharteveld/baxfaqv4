# Bax Music FAQ Frontend

Schone statische Vercel-versie.

Upload de inhoud van deze map naar de root van je GitHub-repository. De repository-root moet direct deze bestanden bevatten:

```text
index.html
app.js
data.js
styles.css
assets/
vercel.json
```

Vercel-instellingen:

```text
Framework Preset: Other
Root Directory: leeg laten, tenzij deze bestanden in een submap staan
Build Command: leeg
Output Directory: leeg
Install Command: leeg
```

Als je nog steeds `404: NOT_FOUND` krijgt, dan deployt Vercel waarschijnlijk een andere repository, branch, root directory of een oud deployment-alias.
